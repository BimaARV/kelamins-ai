### Phase 5 Multimodal & Documents (detail)

- **Document Engine** (`app/documents/`: parser, extractor, pdf, docx, renderer): generic parser dispatches by extension to format-specific readers (pypdf for PDF, python-docx for DOCX, direct UTF-8 for TXT/MD). Report renderer generates PDF (reportlab) or DOCX from structured event data without calling AI.
- **Vision Engine** (`app/vision/`: ocr, analyzer, image_generation): OCR via tesseract-ocr (pytesseract wrapper, `ind+eng` by default). Image analysis sends to Ollama multimodal gateway; falls back to OCR if model not vision-capable. Chart generation via matplotlib (bar/line/pie).
- **DB**: `documents` table (`id`, `filename`, `original_filename`, `file_path`, `document_type` enum (pdf/docx/txt/markdown/image/other), `file_size`, `text_content` LONGTEXT, `meta` JSON, `processing_status`, `event_id` nullable FK, timestamps). Migration: `alembic/versions/a3b9c4d5e6f7_add_document_engine_tables.py`.
- **Endpoints** (all under `/api/v1`): `POST /documents/upload` (parse + store), `GET /documents` (list), `GET /documents/{id}`, `DELETE /documents/{id}`; `POST /reports/generate` (PDF/DOCX from events), `GET /reports` (list), `GET /reports/{filename}` (download); `POST /vision/analyze` (OCR+vision), `POST /vision/ocr` (OCR-only); `GET /status/documents`.
- **Storage** (`storage/documents|reports|images`): Docker named volumes `kela_documents`, `kela_reports`, `kela_images` mounted to api/scheduler/worker. Files stored by UUID-named copies; original filenames in DB.
- **Docker image**: includes `tesseract-ocr`, `tesseract-ocr-ind`, `tesseract-ocr-eng`, `libgl1`, `libglib2.0-0`; pip deps `pypdf`, `python-docx`, `reportlab`, `pytesseract`, `Pillow`, `matplotlib`, `python-multipart`.
- **Config** (`app/config.py`): `TESSERACT_CMD`, `DOCUMENT_STORAGE_PATH`, `REPORT_STORAGE_PATH`, `IMAGE_STORAGE_PATH`, `DOCUMENT_MAX_UPLOAD_MB`, `OCR_LANGUAGES`.
- **Gotcha**: SQLAlchemy column name `metadata` is reserved in declarative API → Document model uses `meta` instead.

## Gotchas (sudah pernah kena — jangan diulang)

1. **MariaDB tidak mendukung `NULLS LAST`** → pakai `.order_by(col.desc())` polos.
2. **`httpx(http2=True)` butuh pkg `h2`** → buat opsional (`try: import h2`).
3. **`threading.Lock` non-reentrant** → jangan panggil method dengan lock di dalam lock (rate_limiter.stats pernah deadlock).
4. **Circuit breaker cooldown** jangan `max(1.0, ...)` → pakai `max(0.0, ...)` biar test sub-second lolos.
5. **Enum vs string di model Event**: `Event.status` itu enum (EventStatus); in-memory objek bisa tetap string bila diset manual — selalu pakai `EventStatus.*` di test, dan kode skalakan (`getattr(x, "value", x)`).
6. **asyncio + asyncmy + sqlite di test**: pakai `StaticPool` + aiosqlite (`sqlite+aiosqlite://`), dan conftest meng-compile BigInteger→INTEGER untuk sqlite. Warning "Event loop closed" dari aiosqlite thread benign.
7. **Backfill alert harus stopper scheduler dulu** (race duplicate `uq_alerts_event_id` kalau dua proses nulis bareng).
8. **Ganti kode container lama**: `docker-compose up -d` TIDAK recreete kalau image tag sama → wajib `--force-recreate`.
9. **AI key**: `OLLAMA_API_KEY_1/2/3` kosong di `.env` → AI worker gradient skip `NO_KEYS`, collectors tetap jalan. Key hanya di memory/env; DB simpan `key_name` saja.
10. Sistem waktu DB naive-UTC; untuk cooldown bandingkan `datetime.now(timezone.utc).replace(tzinfo=None)`.
11. **OllamaKeyManager `keys=[]`** is falsy → falls back to settings (use `keys is not None` guard). Fixed in Phase 5 — passes hermetic test when `.env` has real keys.
12. **FastAPI UploadFile requires `python-multipart`** — must be in `pyproject.toml` dependencies or `File()` endpoints 500.
13. **`libgl1-mesa-glx` removed in Debian trixie** — use `libgl1` instead for Pillow/mpl OpenCL dependency.
14. **`storage/*` Docker volumes** need dirs created and chowned to `kela` in Dockerfile, otherwise `USER kela` gets `PermissionError` on file writes.
15. **`selectinload` chaining untuk event articles**: `selectinload(Event.article_links)` lalu `selectinload(EventArticle.article)` — bukan `Event.article`. Kena `AttributeError: type object 'Event' has no attribute 'article'`.
16. **Tambah file baru di `app/`** mengubah hash layer `COPY app` → invalidate `RUN pip install` → build ulang full pip (lambat). Build bertahap hanya kena kalau isi file berubah, bukan path.
17. **Model field bisa string bukan enum** bila di-set manual (in-memory); selalu `getattr(x, "value", x)` saat membaca (mis. `NetworkTarget.target_type`, `NetworkCheck.status` di test).
18. **`seed_if_empty` cuma nulis kalau tabel kosong** → nambah `NEWS_SOURCE_FIXTURES` di `.env` nggak nongol di DB live. Pakai `sync_source_fixtures` (match `base_url`) yang dipanggil scheduler saat start.
19. **`app.cache.set_heartbeat` pakai TTL 3600s** → jangan dipakai buat nyimpen timestamp jeda lama; kalau perlu Redis key dengan TTL panjang, pakai `get_redis()` langsung (explicit `ex`).
20. **`docker-compose up -d --force-recreate` bisa gagal OCI `Remote peer disconnected`** saat recreate bareng (race cgroup) → `docker start <container>` ulang, biasanya langsung up.
21. **Lokasi weather ad-hoc dari `/weather/query` dibuat `enabled=False`** → nambah adm4 yang sama ke `WEATHER_LOCATIONS` `.env` aja TIDAK cukup; `sync_weather_locations_if_missing` harus di-update biar re-enable row yang match adm4 (log: `synced weather fixtures: 0 added, 1 re-enabled`).
22. **ipwho.is skema berubah-ubah**: `connection.asn_number` pernah hilang (jadi `connection.asn` int), `timezone` berupa objek `{id,...}` — normalizer `app/netinfo.py:_normalize_ipwho` handle `asn int`, `"ASxxxx org"` string, maupun `asn_number`; jangan parse ulang tanpa normalizer.
23. **Jalur test**: service `bot` sekarang `network_mode host` dan TIDAK punya port bind → test harus `docker-compose run` service `api` (mount `/code`, workdir `/code`). Alias juga terlepas dari compose service bot.
24. **`num(value, 0)` mengembalikan `"1.0"` bukan `"1"`** (`round(1.0, 0)` → `1.0` → `str` → `"1.0"`) → jangan dipakai untuk numbering; pakai `str(i)`.
